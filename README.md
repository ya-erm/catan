# Catan

Браузерная игра для 2–4 друзей. Можно создать онлайн-комнату и разослать ссылку либо играть по очереди на одном устройстве. При создании выбираются набор правил и вариант карты.

Звук победы: «Лёгкая фанфара — короткий триумф» из [подборки Звукограм](https://zvukogram.com/category/fanfary/).

## Локальный запуск

Нужен Node.js 20 или новее. Внешних зависимостей нет.

```bash
npm run dev
```

Откройте http://localhost:4173. Для онлайн-партии со вторым игроком используйте другой браузер или отдельный приватный профиль. Для игры на одном устройстве выберите соответствующий режим на стартовом экране. Параметры запуска: `HOST`, `PORT`, `DATA_DIR`, `SECURE_COOKIES`, `PUBLIC_ORIGIN`.

```bash
npm run check
npm test
```

## Комнаты и сохранения

- В режиме одного устройства каждый игрок вводит имя перед началом. После передачи хода экран закрывает карты до подтверждения следующего игрока. Партия сохраняется в `localStorage` этого браузера; её можно продолжить со стартового экрана.
- Комната вмещает до 4 игроков. Для «Новых правил» нужно минимум 2 игрока, для «Классической игры» — минимум 3. Запуск доступен создателю; после запуска состав, набор правил и вариант карты фиксируются.
- Игрок управляет только своим ходом и видит только свои карты ресурсов. Результат кубиков и допустимость действий определяет сервер.
- При броске кубики вращаются, сумма показывается под ними, а поля с выпавшим числом подсвечиваются. Ресурсы летят от конкретного поля к получателю; список добычи показывает игрока, поле, вид и количество ресурса. Нажатие на строку добычи вновь подсвечивает её поле.
- Ссылка содержит код комнаты; личное место определяется защищённой от доступа JavaScript cookie браузера. Обновление страницы и повторный вход по ссылке сохраняют место. На другом устройстве или после очистки cookies это место автоматически не восстанавливается.
- HTTP API принимает действия, SSE доставляет изменения всем игрокам и автоматически переподключается при потере связи.
- Комнаты сохраняются атомарно в JSON-файлы в `DATA_DIR` (локально `./data`). Сохранения переживают перезапуск процесса. В каждом сохранении есть состояние игры и хеши сессий — этот каталог нельзя публиковать.
- Сохранения и секреты исключены из Git через `.gitignore`; перед публикацией изменений проверяйте список подготовленных файлов.
- Завершив партию, создатель может вернуть комнату в ожидание и запустить новую.

## Наборы правил

«Новые правила» сохраняют прежнюю механику: каждый бесплатно ставит одно поселение и получает стартовый набор ресурсов. Поддерживаются 2–4 игрока, а запас ресурсов банка и число построек не ограничены.

«Классическая игра» рассчитана на 3–4 игроков. Начальный игрок выбирается случайно. В первом круге каждый ставит поселение и прилегающую дорогу, во втором — то же в обратном порядке. Ресурсы выдаются только за поля у второго поселения. Запас банка — 19 карт каждого вида; при нехватке карт одного вида для нескольких игроков никто не получает этот ресурс. Ограничения построек: 15 дорог, 5 поселений (город возвращает поселение в запас), 4 города.

В обоих наборах доступны дороги, поселения, города, обмен 4:1, гавани 3:1 и 2:1, разбойник при семёрке, карты развития, «Самый длинный тракт» и «Самое большое войско». Победа — 10 очков.

Классический набор будет уточняться по [официальным правилам базовой игры](https://www.catan.com/understand-catan/game-rules). Существующие комнаты и сохранённые локальные партии без указанного набора остаются в «Новых правилах».

## Генерация карты

«Фиксированная карта» повторяет базовую раскладку гексов, чисел и гаваней в каждой новой партии. «Случайная карта» перемешивает гексы, числа и типы гаваней перед каждой партией; девять прибрежных мест для гаваней остаются прежними. Выбор сохраняется для следующей партии в той же комнате и при локальном сохранении. Уже начатые партии не меняются.

При создании локальной партии каждое место можно назначить человеку или боту сложности 1–3; хотя бы одно место остаётся человеку. Боты автоматически выполняют подготовку, броски, строительство, обмен с банком, розыгрыш карт развития и действия разбойника. В сетевой комнате хозяин добавляет или удаляет ботов в лобби до начала партии. Боты занимают обычные места из лимита в четыре игрока, а их ходы рассчитываются сервером. Сложность и состав локальной партии сохраняются в браузере и в экспортируемом файле.

## Развёртывание

`node server.js` раздаёт игру и API на одном адресе. Данные комнат сохраняются в каталоге `DATA_DIR` (по умолчанию `./data`); этот каталог содержит хеши сессий и исключён из Git. Для публикации нужен HTTPS и собственный домен. Установите `PUBLIC_ORIGIN` в точный адрес сайта и `SECURE_COOKIES=true` при работе через HTTPS.

Файлы `docker-compose.yml` и папки `data/`, `worktrees/`, `archives/`, `review/` относятся к конкретному серверу или рабочим материалам и не входят в репозиторий.

Сервер ограничивает комнату четырьмя игроками, проверяет ревизию для каждого действия, отклоняет запросы с другого сайта и ограничивает размер и частоту запросов.
